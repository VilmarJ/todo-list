# 📝 To-Do List

Uma aplicação de lista de tarefas desenvolvida com HTML, CSS e JavaScript puro, criada com fins de estudo e prática de desenvolvimento front-end.

## ✨ Funcionalidades

- ✅ **Adicionar tarefas** — Digite e salve novas tarefas rapidamente
- ✏️ **Editar tarefas** — Altere o texto de uma tarefa existente
- ✔️ **Concluir tarefas** — Marque tarefas como feitas
- 🗑️ **Remover tarefas** — Exclua tarefas da lista
- 🔍 **Buscar tarefas** — Filtre por texto em tempo real
- 🗂️ **Filtrar por status** — Veja todas, apenas as feitas ou apenas as pendentes
- 💾 **Persistência de dados** — As tarefas são salvas no `localStorage` e permanecem após fechar o navegador

---

## 🚀 Como executar

1. Clone o repositório:
   ```bash
   git clone https://github.com/vilmarj/todo-list.git
   ```
2. Acesse a pasta do projeto:
   ```bash
   cd todo-list
   ```
3. Abra o arquivo `index.html` diretamente no navegador — nenhuma instalação necessária!
